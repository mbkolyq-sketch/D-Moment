# لحظتك — الباك إند + الواجهة (نسخة تجريبية حقيقية)

خادم Node.js + قاعدة بيانات SQLite + واجهة ويب تُخدَّم من نفس الخادم. كل الأرقام والحسابات والمنشورات حقيقية.

## التشغيل محليًا
```bash
npm install
npm start          # http://localhost:3000
```
يتطلب Node 20+. جرّب من جوالك على نفس الشبكة: `http://IP-الكمبيوتر:3000`
(ملاحظة: الكاميرا وتسجيل Google يتطلبان HTTPS على غير localhost).

## ليقدر أي شخص يسجّل ويبحث ويُبحَث عنه
1. انشر المشروع على استضافة Node عليها **قرص دائم** (Render / Railway / Fly.io / VPS) مع HTTPS.
2. اضبط المتغيرات (انظر `.env.example`): `DATA_DIR` (مسار القرص الدائم)، `TRUST_PROXY=1`، `GOOGLE_CLIENT_ID`.
3. Google: console.cloud.google.com → APIs & Services → Credentials → OAuth client ID (Web).
   أضف رابط موقعك في Authorized JavaScript origins، وانسخ الـ Client ID إلى `GOOGLE_CLIENT_ID`.
4. كل من يفتح الرابط يسجّل (بريد/كلمة مرور أو Google) ويظهر في البحث؛ الحسابات كلها في قاعدة بيانات واحدة.

## مشرف (Moderation)
سجّل حسابك أولًا ثم: `npm run make-admin -- your@email.com` — تظهر «🛡️ لوحة الإشراف» في الإعدادات.

## ما هو مفعّل
حسابات حقيقية (بريد + Google) · تسجيل مرة واحدة (JWT 60 يومًا) · بروفايل وصورة شخصية · متابعة (وطلبات للحسابات الخاصة) ·
رفع فيديو/صور (فحص النوع الحقيقي للملف) · فيد حقيقي بتشغيل تلقائي وتتبع المشاهدة الكاملة · إعجاب/حفظ/مشاركة/تعليقات/إشارات @ ·
هاشتاغات وتحديات رائجة · بحث · قصص 24 ساعة · إشعارات · سلسلة اللحظات 🔥 · لحظتي العشوائية 🎲 ·
بلاغات + حظر + خصوصية + إخفاء احترازي بعد 3 بلاغات (فورًا لبلاغ أمان القاصرين) + لوحة إشراف ·
حماية القاصرين: حد أدنى 13، من هم دون 18 حسابهم خاص إلزاميًا، لا يظهرون في البحث لغير متابعيهم، التعليق لمتابعيهم فقط ·
مكافحة Spam: Rate limiting، حد نشر/تعليقات، منع التكرار.

## حدود معروفة (مراحل قادمة)
- **محرر الفيديو** (نصوص/ملصقات/فلاتر/موسيقى/أغلفة): غير موجود بعد — يحتاج معالجة على الخادم (ffmpeg).
- لا تحويل/ضغط فيديو ولا CDN: الملفات تُخدَّم من قرص الخادم (SQLite + قرص محلي مناسبان لبيتا؛ للتوسع PostgreSQL + Object Storage).
- البريد غير موثّق (لا SMTP بعد)؛ حسابات Google موثّقة تلقائيًا. لا استعادة كلمة مرور بعد.
- الروابط `/uploads/...` غير قابلة للتخمين لكنها ليست موقّعة (منشورات الحسابات الخاصة تعتمد على سرية الرابط).
- «حقوق المحتوى»: يوجد بلاغ «انتهاك حقوق الملكية» + إزالة من المشرف، دون بصمة/كشف آلي.
- التحقق من العمر تصريحي (تاريخ ميلاد يُدخله المستخدم).
